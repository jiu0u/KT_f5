## 1. 청사 3곳 재원 분류 → 전력 예측 팀 3단계 기준으로 통일

| | 전 (슬라이드 6장·웹 데모) | 후 (전력 예측 팀 분류기 기준) |
|---|---|---|
| 기준 | 연 발전 ÷ 연 사용 ≤ 30%면 예산 | ① 자가소비율 ≥ 80% ② 전기요금 ≥ 판매가 + 5원 ③ 예산 안 |
| 예산 | 기관별 2억씩 | 공동 3.15억 (대전시 소형햇빛발전소 지원 예산 수준, 가정) |
| 중구청 153kW | 예산 | **예산 1.84억** |
| 대덕구청 131kW | 예산 | **PPA** (1.57억) |
| 교육청 163kW | 예산 | **PPA** (1.96억) |
| 학교 99곳 | 판매 | 판매 (교육용 요금 146.6원 ≈ 판매가 146.92원) |

- 예산 배정 순서: 사용량 자료가 믿을 만한 곳(그린버튼 실측 = 중구청·대덕구청) → 발전량 큰 곳. 결과가 전력 예측 팀 앱과 같게 나옵니다.
- PPA는 청사 일반용 전기요금을 아직 못 구해서 **조건부**입니다. 웹 데모는 165원/kWh로 가정했습니다.
- 전체 숫자는 바뀌지 않습니다: 후보 102곳, 20,576kW, 약 247억 원, 학교 SPC 241.5억, DSCR 1.83 / 최저 1.69.

**반영한 파일:** `docs/slides/s06.html`(+ `deck.html`), `docs/solar_demo.html`, `docs/solar_map.html`(예산 기본값 3.15억, 분류 순서)

**전력 예측 팀 분류 코드 연결:** `solar_classifier.py` 계산을 웹 데모 안으로 옮겼습니다(서버 없이 브라우저에서 계산). `docs/solar_demo.html` → 「설치 방식 판단 (전력 AI)」 탭에서 5곳의 유형·3단계 근거·월별 그래프를 보여 줍니다. 판매가·설치비·금리·예산은 다른 탭 입력값과 같이 바뀌고, 청사 전기요금은 탭 안에서 넣습니다. 교육청 163kW 기준이라 SPC 묶음은 7.54억·시민 23명입니다(문서 8장의 6.95억·21명은 114kW 기준).

## 2. 시연 앱 예시와 발표 숫자는 범위가 다름

- 전력 예측 팀 앱: 5곳 예시(중구청·대덕구청·교육청·판암초·가오초). SPC 묶음은 4곳 6.95억, 시민 최소 21명입니다.
- 발표 전체: 102곳, 247억, 시민 최소 약 725명입니다.
- 발표에서는 이렇게 말하기로 합니다: "앱은 월별 실측 자료가 있는 5곳으로 분류 과정을 보여 주는 예시이고, 전체 규모는 102곳 기준입니다."

## 3. 판암초는 앱 예시로만 씀

- 지붕 AI 항공사진 판독 결과, 판암초에는 **기존 태양광이 있습니다**. 그래서 판암초는 102곳에 들어 있지 않습니다.
- 사용량 자료가 있는 학교가 판암초뿐이라, 앱의 분류 예시로는 그대로 씁니다.
- 102곳 합계에는 넣지 않습니다. 교육청 정보공개 답변(11/22~26)이 오면 다시 확인합니다.

## 4. 판암초 사용량 설명 통일

- 예전 설명: 건축HUB 값 × 1000이 한전 자료와 맞았다.
- 지금 문서: 연면적 12,305.8㎡ × 26~38kWh/㎡로 추정했다.
- 질문이 나오면 **지금 문서 기준(연면적 추정, 신뢰도 낮음)**으로 답합니다. 건축HUB 학교 필지 값은 관사·부속시설만 잡히는 경우가 많아서입니다(유천초 43, 동도초 0kWh/월 등).

## 5. 실측 발전량 기준: 68곳 · 1,200kWh/kW 사용

- 전력 예측 팀: 68곳, 중앙값 1,200, 하위 25% 993.
- 지붕 AI 쪽에서 같은 엑셀로 다시 계산한 값: 66곳, 1,208, 982.
- 차이가 1% 안쪽이라, 이미 슬라이드·데모·펀드 계산에 들어간 **68곳 · 1,200 · 993**을 씁니다. 제외 기준은 전력 예측 팀 문서의 "고장·방치 추정 5곳 제외"입니다.

## 전력 예측 팀 문서·코드에서 고칠 곳

1. **중구청 기존 설비 문구**
   - 지금: "중구는 설치 목록 미제출 → 공식 확인 필요"
   - 고칠 문구: "**중구 정보공개(2026-11-11)로 확인**: 행정재산 건물 목록에 중구청 본청(대흥동 499-1)이 있고, 태양광 설치 6곳 목록(목동·대사동·부사동·태평1동·석교동 행정복지센터, 보건소)에는 없음 → 기존 설비 없음"
   - 문서 9장 "기존 설비 없음이 공식 확인되지 않은 곳"에서 중구청을 빼 주세요(교육청·판암초만 남김).
2. **교육청 163kW 월별 발전량은 그대로 써도 됩니다**
   - 114kW 값 × 163/114로 환산한 값이 지붕 AI 최신 월별표 `docs/청사_월별발전량.csv`와 같습니다(1월 14,767 … 연 217,997kWh).
   - `solar_classifier.py` 주석의 "팀원에게 163 kW 기준 월별 값을 받으면 교체"는 "지붕 AI 163kW 기준 월별표와 같음"으로 바꾸면 됩니다.
   - 문서 9장 "114 kW → 163 kW 갱신 예정"도 "갱신 완료"로 바꿔 주세요.
3. **대덕구청 별관 20kW가 맞습니다** (14.04 + 6kW 두 줄). 지붕 AI 쪽 메모를 고쳐 두겠습니다.
