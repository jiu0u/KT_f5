## 고칠 곳

1. **프로젝트 분석 표(약 88·101·110행)**: "대전 11곳 2,985kW", "32.5억", "49%" → 위 표의 지금 값
2. **S8 제품·정확도 장(130·151·222·660~701행)**
   - 헤드라인 "대전 11곳 적용 결과" → "청사 9곳 분석 · 후보 5곳"
   - 건물별 kW 나열(669행) → 5곳: 중구청 153 · 대덕구청 131 · 교육청 114 · 충북도청 50 · 유성구청 36 (참고: 기설치 제외 4곳 시청 139·서구청 82·충남도청 320·천안시청 729)
   - 핵심 메시지 "49% → 25%" → "44% → 25%, 11곳 중 8곳 AI가 더 정확" (사람 간 0.72는 그대로)
   - 한계 3줄(680·696행) → ① AI 합계 17% 과소 ② 건물 경계 오류 6곳은 손 윤곽으로 해결 ③ 박물관 수동 보정 문구는 박물관이 후보에서 빠졌으니 삭제 가능
3. **데모 영상 콘티(719·722행)**: "예술의전당·미술관" 장면 → 청사(예: 중구청·대덕구청) / "11곳 2,985kW·32.5억" → 5곳 값
4. **S9→S10 전환 멘트(748행)**: "11개 건물 약 3MW, 32억" → 5곳 규모로. 규모가 작아졌으니 "시범 5곳으로 증명 → 확장"으로 톤 조정
5. **S11 실현가능성(816·825·849·870행)**: "시범 2곳→11곳→주차장" → "청사 5곳 시범 → 대전 공공건물(큰 지붕) → 공공주차장". 행정복지센터 분석 결과를 근거로 "왜 큰 지붕부터인가" 한 줄
6. **기대효과(892행)**: 2,985kW·32.5억 → 5곳 값
