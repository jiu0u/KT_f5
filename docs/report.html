이 리포트가 숨기지 않는 것

  • 지자체 배출신고 데이터(유성·대덕·동구, 339개 사업장)는 법정 폐기물 분류명뿐이라 화학물질명과 겹치지 않는다 — CAS 매칭은 전부 NCIS PRTR 52곳에서만 나온다.
  • PRTR의 "취급 확인"은 폐기물 배출을 의미하지 않는다. 132개 (물질,사업장) 쌍 중 57건만 실제 폐기물이동량(>0)이 있고, 나머지 75건은 원료사용 등으로 추정될 뿐이다.
  • 3단계 법적 검증은 규칙 3개뿐이며, 여기 안 걸리면 "적법"이 아니라 "미상"이다. 19종 중 법적 근거가 확인된 건 황산·수산화나트륨 2종뿐.
  • 4단계 거리는 "같은 구인지"만 보는 근접도 프록시다 — 실제 km 거리·운송비가 아니며, 카카오맵/네이버 지도 API 연동이 필요하다.
  • GHG 지정폐기물 합계(12,154톤)가 제안서의 "약 3,600톤"과 재현되지 않는다 — 여러 부분집합을 다 계산해봤지만 일치하는 조합을 못 찾았다.
